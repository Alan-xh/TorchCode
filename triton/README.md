# Triton 简介

块级编程模型：Triton让开发者专注于“程序块”（program/block）级别的逻辑，即一个程序块处理一个数据块（如一个BLOCK_M x BLOCK_N的矩阵块），而非单个线程。这极大地简化了并行编程的复杂性。

SPMD执行模型：Triton采用单程序多数据（SPMD）模型，即所有程序块运行相同的内核代码，但通过各自的program_id处理不同的数据，从而实现数据并行。

自动内存管理：Triton的编译器会自动处理共享内存（Shared Memory）的分配和同步，以及对全局内存的访问进行合并和缓存优化，让开发者能更专注于算法本身。

强类型与编译期优化：通过tl.constexpr等机制，Triton在编译期就能完成大量优化，如常量折叠和循环展开，从而生成高效的GPU机器码。
